# Contributing

Use Node 22.18+ and `npm ci`, then `npm run check`. Start a branch from the revision you intend to improve. Include a concrete example and the relevant lifecycle or package test for behavior changes.

Keep new integrations behind injected adapters. A fake provider should exercise failures without an account or paid call. Include actual backend capabilities and model/version identifiers. If a claim needs a real render, listening judgment, hardware latency or a model comparison, record that evidence separately from unit tests.

Character and lore contributions should identify their source and status: established direction, interpretation, or proposal. Keep Koto Murai the person distinct from KOTO the character. Proposals do not silently become canon through a merged code comment.

Do not commit credentials, private conversation memory, personal source corpora, generated voice datasets or unrelated product assets. Use synthetic fixtures and public sources. Existing code is covered by LICENSE; this project does not grant rights to third-party media or models through an adapter interface.

Package publishing and consumer migrations are owner-reviewed release actions. CI validates the branch; it does not publish.
