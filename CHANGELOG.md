# Changelog

## 2.0.0-alpha.1 — unreleased public overhaul

- Extract Unicode-preserving face parsing, composition, transformations and authored part-to-affect mapping, without private corpus data.
- Add portable character definition and model-neutral runtime with offline expression, explicit identity mode, scoped memory consent, cancellation and forgetting.
- Add an elapsed-time affect bus with immutable versioned frames, exclusive external ownership and explicit stale/release handling. Preserve the old call-counted synth.
- Add a capability-aware voice seam with honest unavailable, ready-audio, played, cancelled and error results. No inference provider is bundled.
- Harden canonical snapshot validation, bounded stale reads and network lifecycle; retain explicit attention submission.
- Repair and verify package exports, ESM/CommonJS declarations and portable browser bundles. Remove unused native/LLM dependencies and replace the unused test framework with Node's test runner.
- Consolidate concept, lore, writing, ecosystem, architecture and API documentation. Preserve old documents for comparison and record the September 2026 research verdicts.
- Add runnable offline examples and a browser playground. No live product consumer was migrated or package published.

## 0.1.0 — historical baseline

Character runtime, expression vocabulary, experimental consciousness/memory, CLI/platform integrations, music intelligence, canonical-spine adapter and WebAudio instrument. The baseline was distributed from Git; its preserved documents contain historical claims and examples.
